Here we give an example of how to create sections without a number, but still add them to the table of contents. 

\phantomsection
\section*{Section 1}
\blindtext[1]
\addcontentsline{toc}{section}{Section 1}

\phantomsection
\subsection*{Subsection 1}
\blindtext[1]
\addcontentsline{toc}{subsection}{Subsection 1}
